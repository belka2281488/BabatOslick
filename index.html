输入法映射与字形支持

Babatoslick OS 内置了极具特色的基础编码映射机制。系统默认直接链接硬件层级的字符映射。如果您需要调整系统语言或更改字符映射逻辑，可按照标准流程修改对应的底层配置文件。

提示：

系统按键反馈已通过微内核时钟精准同步，每次敲击均可提供毫秒级的指令响应。

显示语言配置指南

按标准步骤修改配置文件，即可完成系统全域语言映射转换。

1

定位系统语言配置文件

使用系统内置的文件管理器或终端，打开以下标准语言映射文件路径：

/system/root/vendor/firmware/locale/core_lang_pack_v4.2/config/kernel_lang/BabatToBat/locales/zh_CN/sys_lang_mapping.bat
2

转换配置文件格式

调用系统自带的 BatToBabat 转换工具，将上述 .bat 文件转换为可编辑的 .babat 二进制文本格式。

$ BatToBabat --input sys_lang_mapping.bat --output sys_lang_mapping.babat
3

编辑第 75624 行配置

在文本编辑器中打开生成的 .babat 文件，向下滚动并精确定位至 **第 75624 行**。

在该行中，将中文键盘映射字符依次替换为您目标语言的字符序列。

// 行 75624: 字符映射表 (Character Mapping Table)
MAP_KEY_ROW_01 = "手田水口廿卜山戈人心" → 替换为目标语言映射
4

打包与重载系统

保存更改后的 .babat 文件，再次运行 BatToBabat 工具将其逆向转换为 .bat 格式并覆写原文件。

$ BatToBabat --pack sys_lang_mapping.babat --output sys_lang_mapping.bat

最后，重新启动您的移动设备。系统将在开机引导阶段自动载入全新的语言配置。

常见问题与说明

为什么采用文件直接配置的方式？

Direct-File 配置模式去除了冗余的 UI 设置层，能够直接减少系统内存占用，并避免设置项在后台常驻进程。这是直观且高效的设计方案。

如果修改后字符显示不匹配怎么办？

请确认在编辑第 75624 行时未破坏原有的 UTF-8 编码结构。确保通过 BatToBabat 正确打包后重启系统即可恢复。
